# Novel 0.4.0

生成提示词现在按资料文件分别引用：角色档案、故事圣经、全书大纲、伏笔档案、章节摘要、历史事件、时间线、文风参考。每个变量只使用其对应文件的内容，仍保留人物筛选、历史快照和未来章节过滤。

章节摘要不再回退参考章正文；事件不再合并时间线。使用 `{{参考正文:ch003}}` 明确引用较早章的正文。全书大纲默认使用手动选段，也可明确选择完整文件。视角参数使用 `{{叙事视角}}`，其他叙事指令使用 `{{叙事要求}}`。

旧变量 `{{人物状态}}`、`{{前情}}`、`{{相关设定与伏笔}}`、`{{世界观规则}}`、`{{近期事件}}`、`{{伏笔}}` 已删除，不提供别名或自动迁移。升级后，旧项目的自定义模板必须手动改写；也可先保存 `novel prompt show` 的输出，再执行 `novel prompt reset --yes` 恢复新版默认模板。对标模板默认仍为空。

Windows 独立 CLI 解压后运行 `novel.exe`；需要命令行全局使用时，将所在目录加入 PATH。项目数据和模型设置不包含在分发包中。

详细文件对应表见 [提示词设置使用说明](提示词设置使用说明.md)，命令说明见 [CLI](CLI.md)。
