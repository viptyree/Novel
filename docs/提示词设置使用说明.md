# 提示词与上下文使用说明

## 提示词分类

“提示词设置”包含生成章节、一致性检查、更新记忆三类。每类独立编辑、保存和恢复默认；切换分类保留草稿。旧版本的生成模板保留，新增分类沿用原有默认提示词。

| 分类 | 模板变量 |
| --- | --- |
| 生成章节 | `{{人物状态}}`、`{{前情}}`、`{{相关设定与伏笔}}`、`{{文风参考}}`、`{{事件骨架}}`（必需）、`{{目标字数}}`、`{{叙事要求}}`、`{{章节ID}}` |
| 一致性检查 | `{{章节ID}}`、`{{章节正文}}`（必需）、`{{事件骨架}}`、`{{人物状态}}`、`{{世界观规则}}`、`{{伏笔}}`、`{{近期事件}}`、`{{时间线}}` |
| 更新记忆 | `{{章节ID}}`、`{{章节正文}}`（必需）、`{{人物状态}}`、`{{伏笔}}` |

变量替换、资料筛选和排版均由程序完成，不新增模型调用。更新记忆仍须输出默认 JSON 字段；章号或基本结构不符时不会应用更新。

## 工作台：本章上下文与参考资料

- 默认自动选择主角及骨架中提及的人物，带入最近2章摘要，匹配最多6条较早的相关历史事件。
- 可补选人物、参考章节和具体历史事件。取消自动匹配后，仅使用手选人物和事件；近期摘要另由数量控制。
- 有摘要的参考章使用摘要；明确选择但没有摘要的章会携带该章正文全文，并在来源列表注明。
- 所有作为前情的摘要、事件和参考章必须早于目标章。本章与未来记录不会进入前情。
- 事件和时间线按事件ID合并，时间补入事件，不再复制两份。已有近期摘要的章默认不重复列事件；手选事件可补充细节。
- 风格样例最多2条；可在样例中添加 `source_chapter: "ch003"` 标明出处。重新写旧章时排除后续或来源章号不明的样例，避免样例泄露未来剧情。
- 人物以章初状态呈现，本章可按事件骨架获得新物品、信息或能力；不能把“章初尚未”理解为整章禁止变化。
- 只发送故事圣经的题材、文风与规则字段，省略空字段、空区块及没有设置的叙事指令。
- 伏笔仅携带已埋下的相关线索，省略已解决项及计划回收说明。作者备注不发送。

## 大纲与流水线配置

两者都可以留空。全书大纲适合简短方向，详细未来事件继续保留在剧情目录。生成时不会自动携带整份大纲；如需参考，在工作台勾选大纲选段并填写本章需要的内容。

`config.yaml` 是程序参数文件，不直接进入提示词。模型地址、模型名等已有设置可以满足使用时，无需重复填写。

## 提示词预览与预算

预览弹窗可编辑实际发送的系统和章节提示词。“确定”保留本章临时修改，不立即生成；“取消”或 Escape 放弃本次弹窗内修改。

弹窗统计两段提示词总字符数与估算 tokens，列出自动组装时的资料来源、选择原因及未选入原因。手动改写后，来源列表只作参考，长度统计实时更新。

默认输入预算8000估算 tokens，可在工作台调整。超出预算时需减少资料、精简预览或提高预算；程序不会静默截断手选资料。该估算不是模型 tokenizer 实测，输入预算也不代表模型上下文窗口，须另为正文输出预留空间。

来源或参数变化后需重新确认预览。切换普通 Tab 保留本章临时修改，切换章节/项目或退出应用清除；“恢复自动组装”可随时清除本章覆盖。

## 正文来源与历史状态

设置页可选择当前项目的正文来源目录。存在 `正文/` 的项目默认使用该目录，否则默认使用 `chapters/`。读取、保存、生成、一致性检查及更新记忆使用同一来源，工作台显示实际路径。切换目录不搬移或覆盖任何章节。

覆盖正文或重置前，原文件备份到项目 `.chapter-backups/`。同一章号存在多个文件时会报错，要求明确版本。新章在 `正文` 等普通目录保存为 `第N章.md`，在标准 `chapters` 目录保存为 `chNNN/chapter.md`。

记忆更新时保存人物、故事圣经及伏笔状态快照到 `.memory-snapshots/`。重新生成旧章时优先选目标章之前的快照；没有快照则省略最新状态并明确提示，由作者在预览补充当时状态，绝不假装能从当前档案恢复过去。第一次更新前的老章节未必有快照。

旧章直接更新记忆可能覆盖后续人物状态，软件会拦截早于记忆账本最新章的更新。

作者备注保存在 `author-notes.md`，可从记忆库编辑、在工作台查看，不进入提示词。

## 手测重点

1. 写新章：检查只选本章人物，前情不再出现事件/时间线两份重复。
2. 改旧章：确认本章及未来记录被排除；缺少旧状态快照时显示提示。
3. 手选参考：选择旧章/事件，预览来源列表显示对应手选原因；未来条目不可勾选。
4. 大纲与备注：默认不带全书大纲，备注不出现在提示词；填写选段后才携带选段。
5. 预算：降低预算触发提示，精简预览后可确认生成；提高预算后重新预览使用新预算。
6. 正文来源：核对工作台路径；保存前后确认目标目录正确，覆盖时有备份。
